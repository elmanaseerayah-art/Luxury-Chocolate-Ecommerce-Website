# Luxury Chocolate E-Commerce Website 🍫

A complete e-commerce website developed for **Luxury Chocolate**, a premium chocolate business in Jordan.

The website was built using **WordPress and WooCommerce** to transform the business from primarily social-media-based ordering into a structured online shopping experience.

## Project Overview

Luxury Chocolate is a B2C e-commerce website designed for customers looking for premium Belgian chocolate, chocolate-covered dates, luxury gift boxes, and personalized chocolate gifts.

The website allows customers to browse products, customize selected products, add items to their cart, apply coupons, select delivery options, and complete the checkout process.

## Product Categories

The online store includes several types of products such as:

- Premium Belgian Chocolate
- Chocolate-Covered Dates
- Luxury Gift Boxes
- Customized Chocolate Boxes
- Personalized Chocolate Gifts

Customers can select different product options including flavors, fillings, coatings, box sizes, and personalization options.

## E-Commerce Functionality

The website supports the complete online shopping process:

`Browse Products → Select Options → Add to Cart → Apply Coupon → Select Delivery → Choose Payment → Checkout → Order Confirmation`

Customers can complete checkout either as guests or registered users.

## Personalization

One of the main features of the website is product customization.

Customers can personalize selected chocolate products and gift boxes by choosing available product options and adding personalized details, making the products suitable for birthdays, graduations, weddings, and other special occasions.
